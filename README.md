# Homebrew Tap

This git repository contains the Homebrew tap for all [`raml-dev`](https://github.com/raml-dev) projects.

## Workflow

The `publish` workflow:

1. Downloads the release assets from GitHub Releases of the project that triggered the run
2. Generates the Cask metadata
3. Commits the Cask metadata
